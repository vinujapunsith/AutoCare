# AutoCare - Vehicle Service Management System

AutoCare is a web application developed to manage the activities of a vehicle service center. It helps manage customers, vehicles, appointments, services, mechanics, spare parts and invoices.

## Technologies Used

- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT

## Main Features

- User login and registration
- Admin dashboard
- Customer management
- Vehicle management
- Appointment booking
- Service management
- Mechanic management
- Spare parts management
- Service requests
- Invoice management
- Service history
- Profile settings

## Requirements

- Node.js and npm
- MongoDB

## Installation

### 1. Install Dependencies

Open the terminal in the main project folder and run:

npm run install-all

### 2. Environment Setup

Go to the backend folder and copy the .env.example file

Rename the copied file as .env

Run the following command in the main project folder:

npm run seed

### 3. Run the Backend

Open a terminal in the main project folder and run:

npm run backend

Backend URL: http://localhost:5000

### 4. Run the Frontend

Open another terminal in the main project folder and run:

npm run frontend

Frontend URL: http://localhost:5173

Open the frontend URL in your browser to use the application.
